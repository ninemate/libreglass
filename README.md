# libreglass

Open-source Linux for LG smart TVs, starting with the OLED G1.

*Your screen. Your system.*

A projekt célja a webOS kiváltása egy LG OLED készüléken (LG1212 / O20N) minimális, a tulajdonos által felügyelt Linuxszal.

- Műszaki átadás (magyarul): [docs/handover.md](docs/handover.md)
- PoC init forrása: [docs/poc/poc-init.c](docs/poc/poc-init.c)
